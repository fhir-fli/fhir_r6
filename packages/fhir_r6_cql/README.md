# fhir_r6_cql

Clinical Quality Language (CQL) implementation in Dart for FHIR R6. Parses CQL source into Expression Logic Model (ELM) representation and provides an execution engine to evaluate CQL expressions against FHIR data.

## Features

- CQL parser and translator (CQL to ELM)
- CQL execution engine
- Support for FHIR R6 data types
- UCUM unit conversion

## Getting Started

Add `fhir_r6_cql` to your `pubspec.yaml`:

```yaml
dependencies:
  fhir_r6_cql: ^0.5.0
```
